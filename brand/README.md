# Brand files

The images in this repository's README, drawn so GitHub and npm show them the same everywhere: SVG with no web
fonts and no script.

| File | What it is |
|---|---|
| `logo-light.svg`, `logo-dark.svg` | The pixel G and the GRANTED wordmark as the grnted.co header draws them, for light and for dark backgrounds. The letters are Archivo ExtraBold at 62.5% width, outlined to paths. |
| `blind-test-light.svg`, `blind-test-dark.svg` | The blind test's chart, for light and for dark backgrounds, drawn from [`evidence/blind-71-72.json`](../evidence/blind-71-72.json). |
